# 数据安全与合规

文档编号：DOC-005
适用范围：售前、售前安全评审、客户成功

## 数据分类

| 级别 | 示例 | 存储要求 |
| --- | --- | --- |
| 公开 | 产品文档 | 无特殊要求 |
| 内部 | 配置参数、运营报表 | 需登录访问 |
| 敏感 | 客户会话内容、联系方式 | 加密存储，访问留痕 |
| 极密 | 支付凭证、身份证号 | 加密存储 + 字段脱敏 |

## 加密与密钥

- 传输层使用 TLS 1.3。
- 敏感字段使用 AES-256 加密，密钥托管在云厂商 KMS，每 90 天轮换一次。
- 密钥访问遵循最小权限，运维人员无法直接读取业务密钥明文。

## 数据保留与删除

- 原始会话文本保留 180 天，之后自动归档到冷存储，归档数据保留 2 年后删除。
- 报表与统计数据保留 24 个月。
- 审计日志保留 365 天。
- 客户注销后，30 天内完成数据删除，并向客户提供删除证明。

## 访问控制

- 后台支持 RBAC，内置管理员、主管、坐席、只读四类角色。
- 支持 IP 白名单与企业 SSO（SAML 2.0 / OIDC）。
- 高危操作（批量导出、删除知识库、修改权限）需二次验证并记录审计日志。

## 合规认证

平台已通过 ISO 27001 与等保三级（第三级）测评，测评报告每年更新一次。暂未取得 SOC 2 Type II 报告。

## 数据驻留

数据存储在中国大陆地域。当前不提供境外地域的数据驻留选项。企业版客户可选择华北或华东机房。
