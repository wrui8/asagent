设计原则

1. 事件优先：对话是结果，轨迹是证据。两者始终可切换。
2. 风险显性：审批、预算超限、注入告警用琥珀/红色光晕，不藏在二级页面。
3. 数据质感：数字一律等宽、tabular-nums；成本使用品牌渐变强调。
4. 每次触碰都有回应：hover 有光、点击有涟漪、状态变化有过渡。
5. 未来感在边缘：HUD 角标、发光节点、地平线网格；正文保持高对比、不发光。
